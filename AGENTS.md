# Agent Instructions

## Project: opencode-pushguard

OpenCode plugin + git pre-push hook that runs [desloppify](https://github.com/peteromallet/desloppify) quality checks before `git push`.

## Quick Start

```bash
npm install
npm run typecheck
npm run test
npm run build
```

## Project Structure

```
src/
  index.ts          # Plugin export: hooks + tools
  desloppify.ts     # CLI wrapper (execFileSync)
  utils.ts          # Git command detection
  *.test.ts         # Co-located tests (vitest)
scripts/
  install-hook.sh   # Symlinks pre-push hook into .git/hooks
  pre-push          # Bash hook script (runs standalone)
vitest.config.ts    # Test runner config
tsconfig.json       # TypeScript config
```

## Coding Conventions

- **TypeScript**: strict mode enabled. Use `import` / `export`.
- **Tests**: Co-located as `*.test.ts` alongside source files. Run with `npm test`.
- **Child process**: Prefer `execFileSync(cmd, args[], ...)` over `execSync("string")` to avoid shell injection.
- **Environment variables**: Read at module load time. Validate with `isNaN` / type guards before use.
- **Git hook scripts**: Must work on both GNU/Linux and macOS (BSD grep, no `bc`, no `realpath --relative-to`).

## Key Files

| File | Purpose |
|------|---------|
| `src/index.ts` | Plugin entry. Exports `default { name, hooks, tools }`. `beforeToolCall` intercepts `bash` tool executions to detect `git push`. |
| `src/desloppify.ts` | Wraps `desloppify` CLI commands. Parses strict score and open findings from text output. |
| `src/utils.ts` | `isGitPush(command)` and `parseGitPushCommand(command)` helpers. |
| `scripts/pre-push` | Standalone bash hook with identical logic to the plugin hook. |

## Environment Variables

| Variable | Default | Purpose |
|----------|---------|---------|
| `DESLOPPIFY_SKIP` | `0` | Skip hook entirely |
| `DESLOPPIFY_BLOCK` | `0` | Block push if below threshold |
| `DESLOPPIFY_THRESHOLD` | `95` | Minimum strict score (0-100) |

## Notes for Agents

- Do **not** commit `dist/` — it is in `.gitignore` and rebuilt via `npm run prepare`.
- Do **not** commit `.desloppify/`, `scorecard.png`, or `query.json` — these are generated by the desloppify CLI.
- When adding new CLI wrappers, always use `execFileSync` with an args array.
- When modifying regexes in `utils.ts`, test edge cases like uppercase commands, multiple spaces, and `git.exe` on Windows.
